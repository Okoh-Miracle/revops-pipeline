# RevOps Pipeline — Real Estate Sales Operations

A centralized lead-management and sales-operations system designed for a real estate marketing workflow.

## Live demo

[View Live Demo](https://okoh-miracle.github.io/revops-pipeline/)

Source project: [RevOps Pipeline on Airtable (Real Estate).](https://www.notion.so/RevOps-Pipeline-Real-Estate-249eeb05119580419c79e4cc1b8d15c1)

## What this project demonstrates

- Central lead tracking across Instagram, Realtor.com SMS, ListKit and Meta Ads
- Lead quality classification: Interested / Intent / Hot / Warm / Cold / Ghosted
- Follow-up date logic and a BDR follow-up queue
- Airtable-style pipeline views and KPI reporting
- Campaign performance monitoring
- VA → BDR handoff visibility
- Exportable lead records and editable CRM data

## Original implementation

The underlying system was built around Airtable, Zapier and Make.com, with Gmail, Instagram, ListKit, Realtor.com SMS, Klaviyo and related tooling used across the sales process.

This public repository presents a self-contained browser demo using fictional records. No credentials, private client systems, or real contact information are included.

## Project outcome

The documented project reduced manual reporting time by 80% and gave the team a real-time view of pipeline activity, lead sources and follow-up status.
